> 책상 위에 펼쳐 둔 성적 노트처럼, 학기별 과목과 성적을 기록하고 평점을 한눈에 확인하는 웹 앱입니다.
> ENDPoinT 2026 해커톤 · Team 06

## 이런 걸 할 수 있어요

- 📒 **학기별 과목·성적 기록**: 과목명, 학점, 성적만 적으면 평점이 자동으로 계산돼요.
- 📈 **평점 한눈에 보기**: 누적 평점, 학기별 평점 그래프, 성적 등급 분포를 보여 줘요.
- 🎯 **목표 GPA 시뮬레이터**: 졸업할 때 원하는 평점에 닿으려면 남은 학기에 평균 몇 점이 필요한지 알려 줘요.
- 🔁 **재수강 자동 처리**: 같은 과목을 다시 들으면 예전 성적은 빼고 새 성적으로 계산해요.
- 📝 **과목별 메모**: 평가 기준, 강의실, 수업 내용 등을 과목마다 적어 둘 수 있어요.
- 💌 **미래의 나에게 메세지**: 다짐을 남겨 두면 메인 화면에 늘 띄워 줘요.
- 💾 **백업과 내보내기**: JSON 파일로 백업·복원하고, 엑셀에서 열 수 있는 표로 내보낼 수 있어요.

- 로그인 상태는 브라우저 창(탭)을 닫으면 풀려요. 공용 PC에서도 안심하고 쓸 수 있어요.

## 과목·성적 등록하기

1. **과목·성적** 탭 오른쪽 위의 **+** 버튼을 눌러요.
2. 연도와 학기(1학기·여름학기·2학기·겨울학기)를 고르고 **학기 추가**를 눌러요.
3. 새로 생긴 학기 탭에서 **과목명, 학점, 성적**을 입력하고 **과목 추가**를 눌러요.

- 과목 목록의 **수정**·**삭제** 버튼으로 언제든 고칠 수 있어요.
- 학기가 많아 탭이 넘치면 탭 줄을 좌우로 끌거나 마우스 휠로 넘겨 보세요.
- 과목을 하나도 넣지 않은 학기는 새로고침하면 사라져요. 과목을 하나 이상 넣으면 저장돼요.

### 성적 고르기

| 성적 | 평점 계산 | 이수 학점 |
|---|---|---|
| A+(4.5) · A0(4.0) · B+(3.5) · B0(3.0) · C+(2.5) · C0(2.0) · D+(1.5) · D0(1.0) · F(0) | 포함 | 포함 |
| PASS / FAIL | 제외 | 포함 |
| **-** (아직 성적이 안 나옴) | 제외 | 포함 |

> 💡 지금 듣고 있는 과목은 성적을 **-** 로 두었다가, 성적이 나오면 수정해서 바꾸세요.

### 입력 규칙

- 과목명은 꼭 입력해야 하고 50자까지 쓸 수 있어요.
- 학점은 0보다 크고 30 이하인 숫자여야 해요.
- 한 학기에 같은 이름의 과목은 하나만 등록할 수 있어요.
- 규칙에 맞지 않으면 입력칸 아래에 이유가 빨간 글씨로 나와요.

### 재수강

**앞 학기에 등록한 과목과 같은 이름**으로 과목을 추가하면 재수강으로 처리돼요. 따로 표시할 필요는 없어요.

- 예전 기록은 평점·이수 학점에서 빠지고, 목록에 **R** 표시가 붙어요.
- 재수강한 과목의 성적을 아직 **-** 로 두면, 성적이 나올 때까지 예전 성적으로 계산해요.
- 재수강 규칙
  - 예전 성적이 **C+ 이하**(C+, C0, D+, D0, F, FAIL)일 때만 재수강할 수 있어요.
  - 재수강 성적은 **A0까지**만 받을 수 있어요 (A+ 불가).
  - 예전 과목과 **학점 수**가 같아야 하고, **성적 방식**(A+~F 등급제 / PASS·FAIL)도 같아야 해요.

## 메인 화면 보는 법

- **이번 학기 이수학점 / 총 이수학점**, **수강 과목 수**, **총 평점 평균**(4.5 만점, 소수점 둘째 자리)을 맨 위에 보여 줘요.
- **학기별 평점**: 학기마다 평점이 어떻게 변했는지 꺾은선 그래프로 보여 줘요. 계절학기는 그래프에서 빠져요.
- **성적 등급 분포**: 어떤 성적을 몇 과목 받았는지 원그래프로 보여 줘요.

### 🎯 목표 GPA 시뮬레이터

졸업할 때 받고 싶은 **목표 평점**을 입력하면, 졸업까지 **남은 학점에서 평균 몇 점**을 받아야 하는지 바로 알려 줘요.

```
예) 지금까지 80학점, 평점 3.50 / 목표 3.80 / 졸업 130학점
→ 남은 50학점에서 평균 4.28 이상 (대략 A+ 수준)을 받으면 목표에 도달해요.
```

- 이미 목표보다 평점이 높으면 **목표 달성** 축하 문구가 나와요.
- 남은 학점을 모두 A+로 받아도 닿을 수 없는 목표라면, 최대로 올릴 수 있는 평점을 알려 드려요. 그보다 낮은 목표를 다시 입력해 보세요.
- 졸업 학점은 기본 **130학점**이에요. 학교·학과에 맞게 **설정 → 졸업 학점**에서 바꿀 수 있어요.
- 남은 학점은 모두 A+~F 등급이 나오는 과목으로 들을 거라고 보고 계산해요.
- 성적이 **-** 인 과목이나 FAIL 받은 과목은 아직 이수하지 않은 것으로 보고 남은 학점에 넣어요.

### 💌 미래의 나에게 메세지

**미래의 나에게 메세지 보내기**를 눌러 다짐을 적어 두면, 다음에 들어왔을 때 **지난 나로부터의 메세지** 칸에 보여요. (300자까지)

## 메모

**메모** 탭에서 왼쪽 목록의 과목을 고르고 오른쪽에 자유롭게 적으면 돼요.

- 입력하는 즉시 저장돼요. 저장 버튼이 따로 없어요.
- 과목마다 5,000자까지 쓸 수 있어요.

## 설정

| 항목 | 하는 일 |
|---|---|
| 닉네임 | 메인 화면 인사말에 쓸 이름. 비우고 저장하면 기본값(Google 이름 또는 "게스트")으로 돌아가요. |
| 졸업 학점 | 목표 GPA 시뮬레이터의 기준 학점 (1~300). 비우고 저장하면 130학점으로 돌아가요. |
| 데이터 초기화 | 등록한 과목과 성적을 **모두** 지워요. 되돌릴 수 없어요. |
| JSON 저장 | 과목·성적, 메모, 닉네임, 메세지, 졸업 학점, 목표 평점을 파일 하나로 백업해요. |
| Excel XML 저장 | 엑셀에서 열어 볼 수 있는 과목 표로 내보내요. |
| JSON 불러오기 | 백업 파일 내용으로 지금 데이터를 **통째로 바꿔요**. 필요한 기록은 먼저 백업하세요. |
| 로그아웃 / 게스트 종료 | 첫 화면으로 돌아가요. 저장한 기록은 그대로 남아요. |

## 꼭 알아 두세요

- **로그인해도 과목·성적만 계정에 저장돼요.** 메모, 닉네임, 미래의 나에게 쓴 메세지, 졸업 학점, 목표 평점은 **지금 쓰는 브라우저에만** 저장돼요. 다른 기기에서도 쓰고 싶다면 JSON으로 백업해서 옮기세요.
- 이 브라우저 데이터는 계정별로, 게스트는 게스트끼리 따로 저장돼요.
- 브라우저의 방문 기록·사이트 데이터를 지우면 브라우저에 저장된 기록(게스트 과목, 메모 등)도 함께 지워져요. 중요한 기록은 가끔 **JSON 저장**으로 백업해 두세요.
